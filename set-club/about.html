Portland, OR / About the club

A place on the floor.

Set Club is a fictional neighborhood gym built around one idea: a class should be small enough for the coach to remember what you worked on last time.

01 / Arrive

Start together

The coach walks everyone through the session before the first round. New to a movement? This is the time to try it without a clock running.

02 / Practice

Keep it small

Groups stop at eight. There is time to ask a question, change a weight, or practice a simpler version without losing your place.

03 / Return

Find a rhythm

Strength, conditioning and mat sessions repeat through the week. Pick a familiar class and build from there.
